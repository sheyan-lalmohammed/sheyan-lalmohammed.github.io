Project template

Replication-ready by design.

A standard layout for taking a project from raw data to finished paper, so anyone can rerun the results with one command.

$ tree project/
project/
├── data/
│   ├── raw/          # untouched source files, never edited
│   └── derived/      # built by code only
├── code/
│   ├── 01_build/     # cleaning and merges
│   ├── 02_estimate/  # structural / reduced-form models
│   └── 03_output/    # tables and figures
├── output/         # generated, never hand-edited
├── paper/            # LaTeX, pulls from output/
└── run_all           # one command rebuilds everything
